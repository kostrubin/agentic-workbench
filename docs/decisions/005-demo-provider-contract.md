# ADR 005: A deterministic provider behind the same contract

Status: accepted.

A portfolio reviewer should be able to inspect the complete product without buying model access. The demo should not be a disconnected frontend animation.

Both modes implement the same planner and synthesis interface. The orchestrator, tools, retrieval, persistence, streaming protocol, and citation validation are shared. Demo output is visibly labeled. The seeded narrative requires its source passages; unfamiliar corpora get an honest extractive brief.

Deterministic evaluations prove regression behavior, not model competence. The real adapter is protocol-tested against a local HTTP fixture; live-provider quality requires a separate credential-backed evaluation. There is no fallback from a failed provider to an unlabeled demo result.
